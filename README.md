## 📌 Overview
EcommerceAutomation is a **Selenium WebDriver** automation framework built in **C# with NUnit** to test an eCommerce website's core flows.  
It features a **Page Object Model (POM)** structure, reusable utilities, GitHub Actions CI pipeline, and screenshot capture for failed tests.
